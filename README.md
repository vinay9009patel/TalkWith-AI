# TalkWith-AI

A modern, responsive AI Talk platform featuring:
- 💬 **Roleplay Mode**: Chat with AI companions in various roles.
- 📝 **Practice Mode**: Improve your English with real-time feedback and reports.
- 🎙️ **Voice Integration**: Speech-to-Text and Text-to-Speech support.
- 🎨 **Customization**: Multiple avatars and themes (Dark/Light).

## Tech Stack
- **Frontend**: HTML5, Vanilla CSS, JavaScript (Tailwind CSS, Marked.js).
- **Backend**: Cloudflare Workers (API Proxy).
- **Auth**: Firebase Authentication.

## Deployment
- Hosted on GitHub Pages.
- Backend powered by Cloudflare Workers.
